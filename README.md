\# Projeto Lab: Active Directory no Windows Server 2016



Laboratório de máquinas virtuais com Active Directory: domínio, OUs, grupos e máquina cliente.



\## Ferramentas

\- VMware

\- Windows Server 2016

\- Windows (máquina cliente)



\## O que foi feito

1\. Criação do domínio

2\. Criação das OUs

3\. Criação dos grupos (RH, TI e Financeiro)

4\. Criação dos usuários

5\. Ingresso da máquina cliente no domínio
